    Googleカレンダー連携 (GAS)

    Google Apps Script（無料）を使って、ご自身のGoogleカレンダーの予定を安全に読み込む手順です。

    1. Google Apps Script を開く
      script.google.com にアクセスし、「新しいプロジェクト」をクリックします。
    2. 下のコードを貼り付けて保存
      エディタ内の元のコードを消去し、下記のコードを貼り付けて保存（Ctrl+S / ⌘+S）します。
    3. ウェブアプリとしてデプロイ
      右上の「デプロイ」＞「新しいデプロイ」を選択し、種類の歯車アイコンから「ウェブアプリ」を選びます。
      ・アクセスできるユーザー：「全員」 に設定して「デプロイ」を押します。
      ※「Google はこのアプリを検証していません」と表示された場合
      自作スクリプトのため初回承認時に警告画面が出ます。画面左下の「詳細」をクリックし、下に表示される「（プロジェクト名）（安全ではないページ）に移動」＞「許可」の順に進むと承認が完了します。
    4. 発行されたURLを貼り付けて同期
      表示された「ウェブアプリ URL」をコピーし、上の「URL入力・同期設定」タブに貼り付けて「保存して同期」を押すと連携完了です。
    GASスクリプト例（コピーして使用） 
    function doGet() {
  const cal = CalendarApp.getDefaultCalendar();
  const events = cal.getEventsForDay(new Date());
  const data = events.map(e => ({
    id: e.getId(),
    title: e.getTitle(),
    start: e.getStartTime().toISOString(),
    end: e.getEndTime().toISOString(),
    isAllDay: e.isAllDayEvent(),
    location: e.getLocation(),
    description: e.getDescription()
  }));
  return ContentService.createTextOutput(JSON.stringify(data))
    .setMimeType(ContentService.MimeType.JSON);
}

    Google Apps Script (GAS) のウェブアプリURLを入力すると、今日のGoogleカレンダーの予定を自動取得します（5分ごとに自動同期）。空欄で保存するとサンプル予定に戻ります。
